# Retro Typing Tutor v5 — Seamless Alternating Edition

Single-window, green/amber CRT typing app that auto-alternates **QWERTY ↔ Dvorak** every 4–10 words.
- Uses paired essays (QWERTY-optimized and Dvorak-optimized) as corpus.
- DVORAK spans are simulated via physical keycode mapping (no OS layout change).
- Boot animation, subtle scanlines, periodic refresh surge, VT323 font.

## Run
Just open `index.html` in a modern browser. No server required.

## Keys
- Type continuously; the app handles layout switches per character.
- Backspace deletes; Enter is ignored.
- **↻ Regenerate** builds a new mixed line.
- **🔊 Sound ON/OFF** toggles key click/error tones.
