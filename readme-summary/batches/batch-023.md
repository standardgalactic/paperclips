# Batch 23

**standardgalactic – Experiments Overview**

| Project | Brief Description |
|---------|-------------------|
| **Brick Toss** | Retro 3D block‑drop game built with HTML/CSS/JS. Demonstrates spatial interaction and game logic without external frameworks. Open `experiments/brick-toss/index.html`. |
| **DOS Ops Simulator** | Command‑line simulation modeled after classic text‑mode computing. Access via `experiments/dos-ops-simulator/index.html`. |
| **Kali Lab** | Local security‑research laboratory reconstructing computational history from captures, packets, and flow models. Includes cryptographic primitives, protocol analysis, forensic entropy studies, steganography, etc. |
| **Letter Invaders** | Typing game combining keyboard practice with arcade defense mechanics. Open `experiments/letter-invaders/index.html`. |
| **Terminal Simulator** | Theatrical command‑line simulation inspired by cinematic terminals and retrocomputers. Emphasizes the terminal as a genre rather than reproducing any specific historical OS. |
| **Python Experiment (π Estimation)** | Simple Monte Carlo script estimating π using `experiment.py`. Run with custom sample counts/seed via CLI arguments. |
| **Rust Experiment (π Estimation)** | Rust implementation of the same π estimation (`cargo run`). Provides a comparative look at language/runtime differences. |
