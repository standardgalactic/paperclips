# GOATSS-paper

Summary:

The GOATSS-paper repository contains supplementary materials and code supporting the research paper titled "Mathematical Capabilities of ChatGPT." It includes experiments demonstrating various mathematical reasoning tasks performed by OpenAI's language model, ChatGPT. The repository provides scripts for generating prompts, evaluating responses, and visualizing results across different domains such as algebra, calculus, and logic puzzles. Key components are the dataset of math problems, evaluation metrics (accuracy, fluency), and visualization tools (heatmaps, response timelines). The project aims to rigorously assess ChatGPT's ability to perform symbolic mathematics compared to human experts. Implementation is currently in a proof-of-concept stage with limited datasets and preliminary analysis; further work is needed for broader validation and integration into academic benchmarks.
