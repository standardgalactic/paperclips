# WHANet

Summary:

WHANet is a neural network architecture designed specifically for Super‑Resolution (SR) tasks, focusing on efficiency and performance. It employs a Weighted Hierarchical Attention mechanism to enhance feature extraction from low‑resolution images while maintaining computational lightweight characteristics. The repository contains experimental results plotted across various datasets, with the best-performing pre-trained weights provided for the URban100 dataset at 4× scaling.

Key components include:
- **Weighted Hierarchical Attention**: A novel attention scheme that prioritizes relevant image regions to improve reconstruction quality without excessive resource consumption.
- **Implementation Status**: The code is mature enough to support reproducing results on the URban100 dataset, though further extensions or optimizations may be needed for other datasets.
- **Datasets & Performance**: Demonstrations are available for the URban100 dataset at 4× resolution, showcasing quantitative and visual improvements over baseline methods.
