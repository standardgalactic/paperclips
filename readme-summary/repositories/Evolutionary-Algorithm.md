# Evolutionary-Algorithm

Summary:

The Evolutionary-Algorithm repository implements various evolutionary computation techniques, primarily focusing on genetic algorithms and related optimization methods. It serves as a research tool for MECS 4510 at Columbia University, providing implementations of core components such as selection mechanisms (e.g., tournament selection), crossover operators (e.g., uniform crossover), and mutation strategies (e.g., bit-flip mutation). The project includes example applications like the Traveling Salesman Problem solver and multi-objective optimization demos. Current implementation status is considered intermediate; some features are experimental and may lack thorough testing or documentation. Dependencies include NumPy for numerical operations and Matplotlib for visualizations.

KEYWORDS:
evolutionary algorithms, genetic algorithms, optimization, selection (tournament), crossover (uniform), mutation (bit-flip), Traveling Salesman Problem, multi-objective optimization, MECS 4510, Columbia University, Python library
