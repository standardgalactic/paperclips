# cliodynamics

Summary:

Cliodynamics is an essay repository exploring time-series dynamics in historical phenomena using formal methods from information theory and dynamical systems. It introduces key concepts such as selective projection (Mⱼ(t) = Πⱼ(S(t))), coordination equivalence, consequential aliasing, production/perception asymmetry, indexed recoverability, and minimal coordination messages. The computational experiments implemented via a notebook demonstrate these ideas through visualizations and quantitative validation, including selective projection tests, aliasing rate measurements, noise floor dynamics, and Hall-of-mirrors analysis. The core thesis asserts that the critical issue is whether projections erase meaningful distinctions that affect future outcomes rather than merely quantifying forgetting.

KEYWORDS:
cliodynamics, selective projection, coordination equivalence, consequential aliasing, production/perception asymmetry, indexed recoverability, computational experiments, time-series dynamics, information theory, historical phenomena.
