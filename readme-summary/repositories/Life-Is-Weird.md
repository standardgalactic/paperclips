# Life-Is-Weird

**Summary:**

The Life-Is-Weird repository is a customizable blog starter built on top of Next.js v12, Tailwind CSS v3.0, and MDX v1. It offers modern design support for both dark and light themes. Users can launch the project either locally by cloning the template from GitHub or via an automated setup wizard that integrates with Netlify for deployment.

Key configuration options are provided through environment variables such as `BLOG_NAME`, `BLOG_TITLE`, `BLOG_THEME`, `BLOG_FONT_HEADINGS`, and `BLOG_FONT_PARAGRAPHS`. These settings allow easy integration into various Jamstack platforms. Posts are stored in the `/posts` directory using MDX format, enabling React components for interactive content.

The repository includes testing tooling via Renovate for dependency updates and Cypress with a Netlify Build Plugin to ensure proper rendering and display of templates. Users have options to remove these tools if not needed by deleting specific configuration files or npm packages.
