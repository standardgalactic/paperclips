# Dermatome-Mapping

The Dermatome-Mapping repository provides an interactive, web-based mapping tool for visualizing human dermatomes—regions of the skin innervated by specific spinal nerve roots. It integrates anatomical data with patient-specific imaging (e.g., MRI) to enable clinicians and researchers to correlate sensory deficits with underlying neural structures. The project implements the classic dermatome classification using standardized medical terminology, supporting both educational and research applications in neurology and rehabilitation.

Key components include:
- A JavaScript-powered interactive SVG map displaying dermatomes across body planes.
- Integration with DICOM image formats for importing patient MRI or CT scans.
- An API allowing external scripts to query mapped nerve root locations based on symptom reports.
- Documentation of anatomical conventions, such as the use of Roman numerals (C1–C8) and letter designations (T1–T12) for spinal levels.

The implementation is currently in beta, with ongoing development focused on expanding support for additional imaging modalities and enhancing usability through better accessibility features. Some limitations include reliance on high-resolution anatomical images and potential discrepancies between clinical symptom descriptions and dermatome mappings due to individual variations in nerve innervation.
