# bayesian_causal_inference

The bayesian_causal_inference repository implements Bayesian causal inference methods, focusing on structural equation modeling (SEM) and directed acyclic graphs (DAGs) to estimate causal relationships from observational data. It provides tools for defining causal models using probabilistic programming, estimating posterior distributions of causal parameters via Markov Chain Monte Carlo (MCMC) sampling, and assessing model fit through information criteria like WAIC or LOO-CV. The project includes examples demonstrating causal inference in epidemiology, economics, and social sciences, leveraging libraries such as PyMC3 for Bayesian computation. Current status indicates active development with documentation gaps; some features are experimental and may lack rigorous validation.

KEYWORDS:
Bayesian causal inference, structural equation modeling, directed acyclic graphs, probabilistic programming, MCMC sampling, PyMC3, epidemiology, economics, social sciences, information criteria, WAIC, LOO-CV.
