# node-dynamics

SUMMARY:
The repository "node-dynamics" contains code for a project titled "Modelling Higher-Order Network Dynamics in the Presence of Triadic Interactions," submitted as part of an MSc Mathematics thesis at Queen Mary University of London under supervision by Prof. Dr. Ginestra Bianconi. The project focuses on numerical simulations of node dynamics within networks that exhibit triadic interactions, utilizing Python 3 and several external packages including matplotlib, numpy, scipy, and sdeint. The code is released under the MIT license.

The core functionality is encapsulated in the `NDwTIs` class from the `triadic_interactions.model` module, which simulates node dynamics on such networks. Supporting functions for data computation are provided in `triadic_interactions.computation`, including methods to create incidence matrices, estimate probability distributions (PDFs), joint PDFs, PMFs, and calculate covariance, conditional correlation, and mutual information.
