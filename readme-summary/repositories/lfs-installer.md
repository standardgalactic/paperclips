# lfs-installer

SUMMARY:

The lfs-installer repository provides a script and associated files to install Linux from Scratch (LFS) onto Red Hat based distributions, including CentOS, Fedora, and RHEL. It also supports experimental installations on Ubuntu and Debian with noted limitations. The installer is validated for LFS version 9.0 compatibility with host operating systems such as CentOS 7 and Fedora 30. Users may encounter issues with outdated URLs; the README directs them to check the official LFS downloads page for updated links, particularly for older file versions like File (5.37).
