# portable-warrant

Summary:

The Portable Warrant repository provides software tools and theoretical frameworks for warrant-preservation in digital evidence contexts, as detailed in associated publications (e.g., "The Calculus of Disposition," "Verification Boundaries"). It implements mechanisms to refuse certain warrant transfers when preservation evidence is lacking under specified transformations, domains, and trusted computing base assumptions. The core includes a warrant algebra with operations like attenuation, widening, sequential composition, joins, and distinctions between authentic/sound/complete evidence versus truth. The project references versioned specifications in `scc-reference` (v0.4.2) and reports 34 passing tests for the captured Python suite; BASIC and Forth sources serve as portability profiles without claiming native execution.
