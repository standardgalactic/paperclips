# exoplanets

Summary:

The "exoplanets" repository provides a GraphQL API for accessing exoplanet data from the NASA Exoplanet Archive. Implemented in TypeScript as a Next.js API route and hosted on Vercel, it allows users to filter results by any available field, with options for sorting and pagination. An Apollo Sandbox with documentation is also accessible at https://exoplanets-svarog-0.vercel.app/api/graphql.
