# upc-cn

Summary:

The upc-cn repository contains materials and code associated with a Complex Networks course offered for the Master of Artificial Intelligence program at the Universitat Politècnica de Catalunya - Facultat d'Informàtica (UPC-FIB). The course is instructed by Dr. Sergio Gomez, who teaches at the Universitat Rovira i Virgili (URV). The repository will host resources for four assignments and one final project throughout the semester.
