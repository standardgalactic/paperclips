# ensign

Summary:

The Ensign project provides two distinct typefaces—**Cheiro** and **Clypto**—tailored for cryptographic and creative applications. 

- **Cheiro**: A handwriting-inspired font designed to add a personal touch to digital communications through its fluid, organic letterforms suitable for notes, invitations, and projects requiring a human aesthetic.
  
- **Clypto**: Introduces partial letters that challenge readers to complete them mentally, offering both a stylistic novelty and a light cryptographic element ideal for headers and cryptic messages.

Both typefaces include visual demonstrations showcasing their application in various contexts, such as inverted displays for dark mode compatibility. The README highlights the practical uses and aesthetic qualities of each font without speculating beyond the provided information.
