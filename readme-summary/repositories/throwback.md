# throwback

Summary:

The "throwback" repository creates a nostalgic personal homepage mimicking the aesthetics and functionality of early web technologies from the mid‑1990s. It includes a rainbow animated heading with a scrolling marquee banner, a twinkling canvas starfield background, a local hit counter (stored in `localStorage`), and a guestbook for user signatures (also stored locally). The project is intentionally minimal—consisting solely of plain HTML, CSS, and JavaScript without any build step. Users can run the site by opening `index.html` directly or serving the folder with Python’s HTTP server.

The repository also features "Time Machine" sections linking to historical web artifacts:
- **lisp-1959.html**: Explains PDP‑1 LISP, S-expressions, and prefix notation.
- **forth-1970.html**: Describes Forth's stack model and comparison to RPN.
- **bbs-1985.html** & **gopher-1991.html**: Showcase dial-up BBS screens in an ANSI‑phosphor style.
- **vim-1991.html**: Provides a JavaScript-based modal text editor tutorial with guided lessons on normal/insert/command-line modes and basic editing commands (`dd`, `yy`, `p`).
- **mosaic-1993.html**: Displays a plain NCSA Mosaic-era page, highlighting default link colors and presentational HTML elements like `<blockquote>` and `<hr>`.

KEYWORDS: retro homepage, GeoCities style, marquee banner, hit counter, guestbook, historical web artifacts, LISP 1959, Forth 1970, BBS 1985, Gopher 1991, Vim 1991.
