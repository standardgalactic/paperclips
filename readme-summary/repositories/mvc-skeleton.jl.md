# mvc-skeleton.jl

Summary:

The mvc-skeleton.jl repository provides a minimal Model-View-Controller (MVC) framework implemented in Julia language version 0.3. It requires specific packages including Mustache, Markdown, Dates, SQLite, Morsel, and Autoreload to function. The project includes a web server that runs on port 8000 and is set up to listen for file changes, facilitating rapid development iterations.

KEYWORDS:
MVC framework
Julia programming language
Mustache templating
Markdown formatting
Date handling
SQLite database integration
Morsel storage utility
Autoreload functionality
