# DAS-for-monitoring-landslides

Summary:

The DAS-for-monitoring-landslides repository contains datasets collected via Distributed Acoustic Sensing (DAS) from two documented landslide disasters. The primary purpose is to provide a data resource for research and analysis of seismic signals associated with landslides. Python scripts included in the repository are used to extract relevant signal features, supporting further investigation into landslide detection and monitoring.

Key components:
- DAS technology for recording acoustic signals related to landslide events.
- Two specific landslide case studies embedded within the dataset.
- Data analysis implemented using Python, focusing on feature extraction from seismic data.
- Directly linked to a published paper detailing methodology and findings.
