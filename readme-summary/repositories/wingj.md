# wingj

**Summary**

WingJ is an ImageJ plugin designed for unsupervised and systematic segmentation of *Drosophila* wing pouches and embryos. Developed by Thomas Schaffter, PhD, and Ricard Delgado, PhD, it provides tools for visualizing developmental processes in the fruit fly (Drosophila). The repository includes user manuals, developer guides, and video tutorials demonstrating its applications, such as segmenting the Drosophila wing pouch, embryo, and 3D cell nuclei detection. Citation is required using Schaffter's work on bioinformatics system models.

**KEYWORDS:** WingJ plugin, ImageJ, Drosophila segmentation, developmental biology, unsupervised segmentation, video tutorials, citation required.
