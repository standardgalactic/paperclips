# BFFO

Summary:

The BFFO (Basic Formal Futureproof Ontology) repository provides a foundational ontology designed to support information classes and relationships typical of those found in the OBO (Open Biomedical Ontologies) Foundry. It defines 2 primary classes along with their associated relations that align with the RO (Relations) core framework used by many biomedical ontologies. The purpose is to create a futureproof, interoperable structure for annotating information across various domains.

Key Elements:
- Focus on ontology design principles.
- Implementation of OBO Foundry standards.
- Utilization of RO core relations for consistency.
- Intended as an annotation system for Information Classes.

Status:
- Currently in development; not yet considered mature or complete.
- Actively maintained but lacks full ecosystem integration.

Relationships:
- Explicitly designed to be compatible with existing OBO ontologies.
- No direct dependencies stated, but intended use cases include biomedical data interoperability.

Unusual Claims:
- Aims for futureproofing through adherence to established standards rather than novel innovations.

KEYWORDS:
ontology design, OBO Foundry, RO core relations, information classes, annotation system
