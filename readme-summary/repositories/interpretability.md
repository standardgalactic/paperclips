# interpretability

**Summary**

The “interpretability” repository presents an event‑historical framework for understanding intelligence, AI systems, and complex knowledge structures. It emphasizes that true mechanistic insight comes from reconstructing the irreversible commitments (event‑nodes) that have shaped a system’s current state (texture‑nodes). This approach resolves common interpretability puzzles—such as substitution failure, algorithmic mixture, grokking, and sudden circuit emergence—and extends beyond neural networks to broader knowledge systems.

Key components include:

- **Texture‑nodes**: carry values and modulate behavior within an existing regime.
- **Event‑nodes**: select regimes and impose irreversible constraints on future possibilities.
- The framework’s unifying thesis: mechanistic understanding is the causal reconstruction of these historical, irreversible constraints, not a static snapshot of internal values.

The repository offers multiple entry points for different audiences:

1. **Analogy Guide** – Intuitive explanations using games, tools, and everyday systems (analogy-guide.md).
2. **Concept Explainer** – Non‑technical overview of worldhood, irreversibility, and the importance of history (concept-explainer.md).
3. **Blog Post** – Readable essay for technical audiences linking AI, philosophy, and system design (blog-post.md).
4. **Briefing Document** – Executive summary framing interpretability for safety, governance, and institutional resilience (briefing-document.md).
5. **Technical Paper** – Full formal exposition with typed causal graphs, two‑channel mediation, kernel histories, Spherepop/RSVP grounding, and applications to mechanistic interpretability (technical-paper.md).

The README explicitly states that the framework is still under development for rigorous validation but provides a coherent methodology for historical causal reverse engineering.

**KEYWORDS:** event‑historical interpretability, texture‑nodes, event‑nodes, irreversibility, mechanistic understanding, substitution failure, algorithmic mixture, grokking, circuit emergence, neural networks, knowledge systems, formal causal graphs.
