# retro-fps

Summary:

The retro-fps repository develops a first-person shooter game with a retro aesthetic, implemented from scratch using C11 and Direct3D 11 (D3D11). It parses level data (.map files) from Quake 2 (Valve), utilizing Trenchbroom for map editing. The project is currently in an early work-in-progress stage, primarily focused on core functionality rather than extensive feature sets or polished graphics. Building requires Visual Studio x64 native tools; default builds are debug configurations unless specified otherwise. Runtime issues like missing stdalign.h can be resolved by updating to the latest Visual Studio 2022 build tools. Texture assets are sourced from Ben "Makkon" Hale, with non-included textures due to cost constraints for git LFS storage.
