# GarysBasic

Summary:

GarysBasic is an interpreter for the BASIC programming language implemented using FreeBASIC. Its primary purpose is to provide a lightweight, accessible environment for executing BASIC scripts without requiring additional runtime dependencies beyond those provided by FreeBASIC itself. The repository contains source code for the interpreter along with example programs demonstrating basic functionality such as arithmetic operations, variable assignment, and simple I/O.

The implementation leverages concepts from early computing environments where interpreted languages were common due to their ease of use and rapid development capabilities. Notably, GarysBasic adheres to standard BASIC syntax while incorporating modern features available in FreeBASIC like type safety and structured programming constructs.

Status: The project is considered a work-in-progress with limited feature set; core interpreter functionality (tokenization, parsing, execution) is implemented but lacks advanced libraries or debugging tools typical of production-grade interpreters. Maturity level reflects experimental stage rather than ready-for-production use.
