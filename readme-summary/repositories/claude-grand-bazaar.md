# claude-grand-bazaar

Summary:

The Claude Grand Bazaar repository serves as a plugin marketplace specifically designed for integration with Claude Code and Cowork environments. It is built around five core primitives: Skills (representing knowledge and reasoning capabilities), Hooks (for automated safety measures), Subagents (specialized focused agents), Connectors (to link external systems), and Language Server Protocol (LSP) servers (providing real-time code intelligence). The project adheres to a philosophy prioritizing quality over quantity, aiming for five high-quality plugins rather than numerous less effective ones. Each plugin is research-grounded, thoroughly documented, composable, opinionated, and rigorously tested in practical applications. As of version v0.1.0, the marketplace is still in its early stages (open to contributions only after reaching version 1.0). The repository is licensed under the Hippocratic License 3.0.
