# userspace

Summary:

The "userspace" repository presents a theoretical framework called Mereological-Space-Ontology (MSO) that challenges traditional stable object classifications by treating scale as an essential dimension. It introduces a glyph-string system to encode regime transitions across various domains—from microphysical carriers to cosmic structures—using a long composite token representing the entire scale spectrum. The MSO symbol table provides symbols for each regime, facilitating both ontological and epistemic organization of the world.

KEYWORDS:
MSO framework, mereology, scale dimension, regime transitions, glyph-string encoding, cosmological structure, microphysics to galactic scales, symbolic taxonomy.
