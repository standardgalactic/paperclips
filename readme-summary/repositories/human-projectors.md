# human-projectors

Summary:

The human-projectors repository explores humans as "lossy entropy-respecting projectors," a concept rooted in information theory where human cognition and perception inherently discard some information while attempting to preserve overall meaning. The project implements algorithms and models that simulate this behavior, aiming to understand how neural networks and cognitive processes can be mathematically described within an entropy framework.

Key components include:
- **Entropy Models**: Utilizing Shannon's entropy to quantify the lossy nature of human perception.
- **Neural Network Simulations**: Implementing simplified neural network architectures that mimic selective information retention.
- **Cognitive Bias Frameworks**: Incorporating studies on cognitive biases as manifestations of entropy-respecting projection.
- **Experimental Software**: Providing tools for simulating sensory input processing and output generation, demonstrating how humans project external stimuli with inherent loss.

The repository is currently in an experimental stage, lacking extensive documentation or widespread adoption. It serves primarily as a research artifact rather than a production-ready application, indicating ongoing development and refinement of the underlying theories and models.
