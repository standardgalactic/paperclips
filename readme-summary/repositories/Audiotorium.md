# Audiotorium

Audiotorium is an open-source software project dedicated to creating interactive audio‑visualizers. It provides a framework for generating dynamic visual representations of audio signals, enabling users to explore sound through customizable graphical interfaces. The core concepts involve mapping audio properties (such as frequency, amplitude, and phase) onto visual elements like lines, shapes, and color gradients. Notable features include support for various audio file formats, real-time processing capabilities, and extensibility via plugins. The implementation leverages the Processing programming language and relies on libraries such as FFTW for efficient Fourier transforms. While largely mature, some experimental modules remain under development. KEYWORDS: Audiotorium, audio-visualizers, interactive, Processing, FFTW, frequency mapping, real-time audio processing, plugin architecture.
