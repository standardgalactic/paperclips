# arabic-flashcards

Summary:

The Arabic Flashcards repository provides educational flashcard software designed to help users learn Arabic language vocabulary through spaced repetition. It leverages the Noto Naskh Arabic Variable Font (NotoNaskhArabic-VariableFont_wght.ttf) which includes multiple font weights via a single variable file, enabling selection of intermediate styles not available in static fonts. Users can install required font files and use their application's font picker to access all available styles. The README links to resources for understanding variable fonts, installation guides for macOS, Linux, and Windows, as well as specific guidance for Android app developers. Licensing information is provided via OFL.txt detailing usage permissions, restrictions, and requirements.
