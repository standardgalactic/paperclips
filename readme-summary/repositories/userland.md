# userland

Summary:

The Userland repository is an experimental project focused on interactive fiction and related systems. It explores concepts such as stigmergy, where agents interact with their environment to create feedback loops, through the "Stigmergic Berm" paper. The suite of papers (Signal Before System, Form Before Command, Extraction Before Acceleration, Layering the World, Inscription Before Collusion, Prejudice Before Agency) collectively articulate a framework for designing systems that prioritize signal generation over system design, form before command, and other stigmergic principles.

Userland serves as an interactive fiction platform, complemented by Orbit Lab, a space simulator, and Change the Space, an audio-visualizer. These components demonstrate practical applications of the theoretical frameworks presented in the linked PDFs. The implementation is currently experimental and not yet mature for production use, as indicated by the README.
