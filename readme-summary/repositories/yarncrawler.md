# yarncrawler

**Summary**

Yarncrawler is a research project that investigates the **Yarncrawler Framework**, a model of self‑repairing computation. It draws connections between:

* **RSVP field theory** (scalar Φ, vector 𝒗, entropy S) – providing a formal mathematical foundation for how information and energy flow in the system.
* **Stigmergic processes** observed in natural ecosystems such as terra preta soils, illustrating how decentralized cues can lead to durable outcomes.
* **AI architectures**, notably mixture‑of‑experts combined with retrieval‑augmented generation (RAG), showing practical applications of self‑repairing computation.

The project’s core contribution is the **Yarncrawler Functor Master Equation (YFME)**, which frames semantic parsing as a process of local patching and global repair using sheaf theory. Cultural analogies—e.g., terra preta soils acting like long‑lived Yarncrawlers—highlight how biological stigmergy can inform computational resilience.

Key components include:

* `manuscript/` – LaTeX draft of the essay *Yarncrawler in Action*.
* `simulations/` – Python models simulating stigmergic berms and RSVP fields, with visualizations (Figures 1‑7) showing emergent behavior.
* `figures/` – Supporting diagrams and plots that illustrate repair dynamics.

The README emphasizes the project’s **interdisciplinary nature**, linking mathematics, biology, anthropology, and computation to demonstrate how systems can endure through recursive reweaving. Future work envisions synthetic terra preta ecosystems and “terra preta rain” as analogues for scalable sanitation and self‑maintaining digital environments.

**KEYWORDS:** Yarncrawler Framework, RSVP field theory, stigmergy, terra preta, self‑repairing computation, semantic parsing, sheaf theory, mixture-of-experts, retrieval-augmented generation.
