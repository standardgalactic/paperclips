# skill-abstraction

**Summary**

The repository contains the implementation of **STAR (Learning Diverse Robot Skill Abstractions through Rotation-Augmented Vector Quantization)**—a framework designed to advance both skill learning and composition for complex robotic behaviors. It builds on prior work such as VLAs, VQ‑BeT, and QueST by introducing a rotation‑augmented vector quantization approach that improves performance across several robot benchmark suites (LIBERO-Object, LIBERO-Spatial, etc.). The framework achieves state‑of‑the‑art results—e.g., 98.3 % on LIBERO‑Object, 95.5 % on LIBERO‑Spatial, and comparable or superior scores on other benchmarks—demonstrating its effectiveness in learning diverse robot skills.
