# antivenom

Summary:

The antivenom repository focuses on rhetorical analyses related to vaccine injury debates, epistemic fragmentation, and the historical migration of data schemas. It contains four detailed PDFs exploring counterfactual narratives before classification, failures in epistemic transport due to fragmentation, repartitioning conventions via analogies (pebbles, punched cards), and a reversibility gate concerning evidence, delay, and action under unsettled claims. An infographic visualizes these concepts.

KEYWORDS:
antivenom repository, vaccine injury debate, epistemic fragmentation, data schema migration, rhetorical analysis, counterfactual narratives, evidence delay action, infographics
