# supercube

Summary:

Supercube is a physical construction project that serves as an interactive demonstration of the Pythagorean Theorem. It combines elements of puzzle assembly, origami (crinkle cut technique), and geometric visualization. The repository includes images documenting the building process from unassembled parts to the final assembled cube, along with proof visualizations showing the theorem in action using paper straws and prototype materials.

Key concepts include:
- Bridge to Terrabythia: metaphorical reference
- Pythagorean Theorem proof implementation via physical model
- Crinkle cut technique for folding Supercube from paper straws
- Aphantasia-related notes on visualization challenges

The project is presented as an extremely rough prototype, indicating it may be incomplete or experimental in nature. It references resources and images that likely provide additional context but are not detailed in the README.
