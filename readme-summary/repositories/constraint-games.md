# constraint-games

Summary:

The constraint-games repository focuses on developing and experimenting with game theory models that incorporate various constraints. It provides a collection of Jupyter notebooks designed to be fully reproducible by explicitly documenting seeds, input datasets, and the specific software environments used for each experiment. The projects within explore how different constraints affect strategic decision-making in games, utilizing concepts from game theory such as Nash equilibria, Pareto efficiency, and coalition formation under resource or time limitations.

The repository is currently in an experimental phase, with many implementations still lacking thorough testing or documentation beyond the basic reproducibility notes. It serves as a companion to larger theoretical works on constrained strategic interactions rather than a standalone software product.
