# type-so-fast

Summary:

TypeSoFast is a typing speed test application for Indonesian language, implemented using React and TypeScript. It measures performance based on 5 correct keystrokes per word (WPM), counts each character as one keystroke (excluding special keys), and calculates accuracy as correct keystrokes divided by total keystrokes plus backspace instances. The vocabulary includes words sourced from news articles on Kompas.com and Kumparan.com, which may contain typos, slang, or foreign terms. Users are encouraged to contribute by forking the project, editing the `words.ts` file in the constants folder, and submitting pull requests.
