# SemanticWeb

SUMMARY:
The SemanticWeb repository contains a Java implementation of the PageRank algorithm applied to semantic web graphs. Users can compile and run the program with parameters for graph input, damping factor (lambda), and tolerance (epsilon). Results demonstrate sensitivity of PageRank scores to epsilon variations, showing minimal impact on ranking order across different epsilon values. Adding artificial authorities and hubs affects rankings significantly, highlighting potential manipulation through self-links or proxy pages. The influence of lambda is also examined, revealing how extreme values alter score distributions dramatically.

KEYWORDS:
Semantic Web, PageRank algorithm, Java implementation, graph analysis, damping factor, tolerance parameter, semantic graphs, ranking sensitivity, manipulation detection, mathematical frameworks.
