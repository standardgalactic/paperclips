# New-AI-Benchmark

Summary:

The New-AI-Benchmark repository aims to provide a standardized set of 100 benchmark problems designed to evaluate the capabilities of artificial intelligence systems. The problem list, currently encrypted and titled AIBlenchmarkOProblems.docx, will be made publicly available on February 1, 2026, along with its decryption key and an unencrypted version labeled AIBenchmarkProblemsFinal.docx. This distinction is crucial; the final version has undergone rigorous review to correct errors identified in the initial draft (AIBlenchmarkOProblems.docx), which contained approximately 25 flawed problems deemed "Flawed" by the creator, Ernest Davis.

Davis explains that the delay in releasing the dataset was due to a bet placed on March 24, 2025, where he committed to uploading the complete and error-free dataset. The associated Bet.html file outlines this wager. The repository also serves as a verification point for changes made solely to correct errors without altering the underlying content or intent of the benchmarks.
