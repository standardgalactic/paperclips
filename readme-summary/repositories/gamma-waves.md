# gamma-waves

Summary:

The repository “gamma-waves” hosts an interactive visualization tool called **Entropy’s Edge v3**, which implements a fully interactive Relativistic Scalar‑Vector Plenum (RSVP) field simulator. It allows users to manipulate key parameters such as κΦ, κS, λ, γ, and μS to reweight Φ–S dynamics, toggle visibility of potential Φ brightness, entropy color mapping, vector fields, or faction overlays via checkboxes, adjust arrow sparsity with a Vector Density slider, and capture snapshots of the current display. The simulation supports playback controls (Next/Prev/Auto/Restart) for navigating precomputed temporal turns.

The visual representation maps **color (blue→red)** to entropy S, **brightness** to potential Φ, and **arrows** to vector flow 𝒗, with an optional faction overlay available. Deployment is straightforward: upload all files to a GitHub repository named `entropys_edge_web_v3`, enable GitHub Pages on the main branch/root, and access it at `https://yourusername.github.io/entropys_edge_web_v3/`. No backend services are required; the entire application runs in the browser.
