# Lynx-hallucination-detection

Summary:

The Lynx Hallucination Detection repository is focused on identifying and mitigating hallucinations in large language model (LLM) outputs. It provides setup instructions for creating a local environment using pyenv, along with Poetry dependency management files. The repository includes detailed guides for inference and fine-tuning setups using mcli and vLLM frameworks.

Key components:
- Inference and Finetuning documentation located in `mcli_finetuning.md`, `mcli_inference.md`, and `vllm_inference.md`.
- Utilizes pre-commit hooks for code standardization.
- Requires environment variable configuration from `.env.example` to `.env`.
