# Zen

Summary:

Zen is an open-source, development-stage framework for performing density functional theory (DFT) combined with dynamical mean-field theory (DMFT) computations, targeting the investigation of strongly correlated electronic systems. It comprises several interdependent modules: ZenApps, ZenTools, ZenCore, Dyson, iQIST, and Flink, each at various developmental stages as indicated by their version tags. The current release is v0.4.20-devel.211116, explicitly marked as not yet production-ready. Licensed under the GNU General Public License Version 3, Zen aims to provide a comprehensive suite for researchers in quantum materials science, though users should be aware of its incomplete implementation status.

KEYWORDS:
