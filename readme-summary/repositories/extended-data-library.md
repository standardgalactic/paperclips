# extended-data-library

Summary:

The Extended Data Library is a collection of high-performance Python libraries and tools designed for data processing, configuration management, logging, and cloud integrations. It includes several packages housed in a monorepo at GitHub (https://github.com/jbcom/extended-data-library):

- **extended-data-types**: Provides typed utilities for various data formats including YAML, JSON, TOML, HCL, Base64, file paths, strings, lists, and maps.
- **lifecyclelogging**: Offers lifecycle-aware logging with rich output capabilities, verbosity control, and message storage features.
- **directed-inputs-class**: Facilitates transparent input handling from environment variables, stdin, and configuration files.
- **vendor-connectors**: Implements universal cloud and service connectors for platforms such as AWS, GitHub, Slack, Vault, Anthropic, Cursor, and Meshy.
- **secretssync**: An enterprise-grade secret synchronization pipeline implemented in Go.

The documentation for the entire library is available at extendeddata.dev (https://extendeddata.dev).
