# IsingModels

The IsingModels repository implements numerical simulations and analytical tools for studying the Ising model, a fundamental statistical mechanics model used to describe ferromagnetism in statistical physics. It provides code for simulating both classical (zero-field) and quantum (transverse field) Ising models on various lattice geometries (e.g., square, triangular), enabling researchers to explore phase transitions, critical phenomena, and emergent behaviors such as spontaneous magnetization and critical exponents.

Key components include:
- Monte Carlo algorithms (Metropolis, Heat Bath) for Markov chain sampling.
- Visualization utilities for plotting spin configurations and order parameters over time.
- Analytical extensions like finite-size scaling analysis to extract universal critical properties.
- Integration with Python libraries (NumPy, Matplotlib) for data analysis and reproducible research workflows.

The implementation is considered mature enough for educational and research purposes but lacks advanced features such as parallel processing optimizations or support for higher-dimensional lattices beyond 3D cubes.

KEYWORDS:
Ising model, statistical mechanics, Monte Carlo simulation, ferromagnetism, phase transition, critical phenomena, Python, NumPy, Matplotlib.
