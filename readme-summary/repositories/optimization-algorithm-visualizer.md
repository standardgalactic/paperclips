# optimization-algorithm-visualizer

The repository “optimization-algorithm-visualizer” provides an interactive web application built with React, JavaScript, TailwindCSS, and the Geogebra API to visualize how various metaheuristic algorithms converge on optimal solutions for convex function optimization problems. It demonstrates algorithmic steps through dynamic graphical representations, enabling users to explore convergence behaviors visually.
