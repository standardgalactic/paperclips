# StockWatcher

Summary:

StockWatcher is a starter project generated by GWT WebAppCreator designed for developing web applications using Google Web Toolkit (GWT). Its primary purpose is to provide a minimal, runnable environment for building and debugging GWT projects. The repository includes instructions for importing the project into Eclipse (recommended) via the "Existing Projects into Workspace" feature, as well as command‑line build options using Apache Ant (`ant hosted`, `ant war`, etc.). It supports launching the web app in hosted mode within Eclipse with a built‑in debugger and compiles for deployment when run with appropriate Ant targets. Compatibility notes specify successful testing on Eclipse 3.3/4.x and Ant 1.7.1, while other IDEs require manual configuration to match the Ant build process.

KEYWORDS: StockWatcher, GWT WebAppCreator, Google Web Toolkit, Eclipse, Ant, web application development, hosted mode, debugging, command line build.
