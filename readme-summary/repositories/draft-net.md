# draft-net

**Summary**

The *draft‑net* repository hosts an **RSVP Writing Suite**, a constraint‑first environment for authorship where documents are modeled as evolving scalar‑vector‑entropy fields (Φ = semantic density, v = directional narrative flow, S = structural disorder). Built on Bash/Vim interaction and Python for computation, the suite provides CLI tools (`rsvp-parse`, `rsvp-entropy`, `rsvp-flow`, etc.) to analyze screenplay or prose texts using RSVP field theory and Spherepop’s event‑history model. It includes Vim plugins for in‑editor diagnostics, transform passes (e.g., redundancy reduction, lamphrodyne smoothing), and a test suite via pytest. The README emphasizes that the tools are not generic AI assistants but expose writing as deterministic field dynamics with explicit mathematical definitions.
