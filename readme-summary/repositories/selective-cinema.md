# selective-cinema

Summary:

Selective Cinema is an experimental project that explores the use of blink-rate glasses to multiplex narrative experiences. It combines interactive technology with film studies, aiming to alter perception and storytelling through visual stimuli. The repository contains LaTeX source files (main.tex) for generating documentation related to the Blink-Rate Glasses system, along with required packages for typesetting.

The implementation is currently in a draft state as of September 2026, indicating ongoing development and refinement. It focuses on theoretical frameworks from film studies and cognitive science, particularly examining how altered visual perception can affect narrative engagement and emotional response.
