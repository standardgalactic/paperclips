# pixels-pygame-palace

Summary:

The "pixels-pygame-palace" repository serves as an assets directory for a game developed using PyGame, focusing on pixel art style. It houses various media files required for gameplay, including fonts (CC0 and open-source), sound effects (WAV, OGG, MP3), background music tracks (OGG, MP3), character and object sprites (PNG), level building tilesets (PNG), 3D models (GLTF, GLB, OBJ), and UI elements/backgrounds (PNG, JPG). All assets are sourced from platforms that provide CC0 or similarly permissive licenses, ensuring free use. The repository leverages Git LFS for efficient storage of large media files, maintaining a lightweight primary repository while keeping all necessary game assets accessible.
