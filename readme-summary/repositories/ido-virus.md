# ido-virus

Summary:

The ido-virus repository implements the Virus Infectious Disease Ontology (IDO Virus), an extension of the broader Infectious Disease Ontology (IDO). It adheres to OBO Foundry standards and is grounded in the Basic Formal Ontology. The ontology specifically addresses terminology used by virologists, encompassing virus, prion, satellite, viroid classifications, epidemiology, pathogenesis, and treatment aspects related to infectious diseases.
