# random_jokes

Summary:

The random_jokes repository contains a simple web application designed to generate humorous content using HTML, CSS, and JavaScript. It leverages the icanhazdadjoke.com API to fetch jokes dynamically. The project includes a built-in tweet button that allows users to share generated jokes directly on Twitter (now X). Currently, the repository outlines plans to expand social media integration features for WhatsApp and Facebook in future updates.

KEYWORDS:
random jokes generator, icanhazdadjoke API, HTML CSS JavaScript, tweet button, social media integration, WhatsApp, Facebook.
