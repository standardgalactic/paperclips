# endohiff

Summary:

The endohiff repository is a research project inspired by endosymbiosis, focusing on creating an "evolved environment" (host) that influences the evolutionary trajectory of "symbionts." It uses computational simulations to test whether shaping the fitness landscape can lead symbionts to achieve higher fitness scores compared to non-agential environments. The project is optimized for a single CUDA-enabled GPU and relies on Snakemake workflows for managing experiments, visualizations, and performance charts across different environmental configurations.
