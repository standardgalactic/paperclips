# Chronic_Lymphocytic_Leukemia

Summary:

The repository contains codes and scripts developed to support the research presented in the paper titled "Mitochondrial Heteroplasmy is a Novel Predictor of Chronic Lymphocytic Leukemia (CLL) Risk." It includes Python and R scripts, along with associated data files, that implement methods for analyzing mitochondrial DNA heteroplasmy levels as predictors of CLL risk. The code performs statistical analyses, utilizes machine learning models to correlate heteroplasmy variation with patient outcomes, and visualizes results through plots and tables.

Key components include:
- Data preprocessing pipelines for handling genetic sequencing data.
- Statistical modeling frameworks employing logistic regression and random forest algorithms.
- Visualization tools using matplotlib and seaborn for graphical representation of risk predictions.
- Documentation files explaining the methodology and assumptions behind the predictive model.

The implementation is noted to be a work in progress, with ongoing refinement based on feedback from the scientific community. The repository does not claim completeness but rather serves as an open-source resource for replication and further investigation into mitochondrial heteroplasmy's role in CLL development.
