# TARTAN

summary: TARTAN is an architecture for artificial intelligence that shifts from predictive approximation to **constraint closure**, modeling observations as projections of a shared underlying state and requiring reconstruction through global consistency rather than local fit. Grounded in the Relativistic Scalar–Vector Plenum (RSVP) framework, inference involves satisfying projection constraints and dynamical admissibility conditions, treating perception, reasoning, and modeling as processes of entropy reduction via structural reconciliation. The system uses a staged closure protocol to repair inconsistent regions, refine resolution across ambiguous boundaries, or expand representational capacity for previously unmodeled structure. A consistency operator defines globally admissible world-states; hallucinations are reinterpreted as failures of constraint satisfaction, resolved by enforcing global consistency.

KEYWORDS: TARTAN architecture, constraint closure, Relativistic Scalar–Vector Plenum (RSVP), projection constraints, dynamical admissibility conditions, entropy reduction, cohomological obstructions, staged closure protocol, consistency operator, hallucinations reinterpreted.
