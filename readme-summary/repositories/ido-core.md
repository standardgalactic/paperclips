# ido-core

The ido-core repository implements an innovative decision-making framework called Ido, designed to model and simulate complex adaptive systems. It provides core libraries for agents that can learn, adapt, and interact within simulated environments using principles from multi-agent systems theory. The project leverages probabilistic programming and reinforcement learning algorithms to enable autonomous behavior in simulated ecosystems.

Ido-core is intentionally kept modular to allow integration with other simulation frameworks like NetLogo or AnyLogic, facilitating cross-disciplinary research on emergent behaviors. While the core engine is functional for prototyping purposes, it remains an early-stage implementation lacking comprehensive documentation and extensive testing suites.
