# industrial-ecologies

Summary:

The industrial-ecologies repository contains deterministic headless Blender simulations modeling various facilities such as factories, laboratories, food processing units, recycling systems, and ecological material cycles. It treats each facility as an integrated material‑energy‑water system where recovery paths are visible, losses are explicitly named, and no waste stream is left unmodeled. The project includes a render script (`render_all.sh`) that outputs PNG images, reusable Blender `.blend` files, and JSON sidecars with nominal process metrics for each scene (referenced in `experiments/METRICS.md`). Two interactive interfaces are provided: *Nothing Vanishes* – an interactive explorer, and the *Output Visualizer* – a live demo. The repository adheres to MIT licensing.

KEYWORDS:
Industrial Ecologies, Blender simulations, material cycles, waste recovery, deterministic modeling, Nothing Vanishes interface, Output Visualizer demo, MIT license.
