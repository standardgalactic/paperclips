# calculator

Summary:

The "Calculator" repository demonstrates a unique numeral system called Dactyl numerals, where numbers are depicted as growing entities starting from a seed-like zero to the largest digit 9. It includes visual representations of both standard decimal calculators and those formatted with Dactyl numerals. The project references an accompanying Dactyl Clock for additional context.
