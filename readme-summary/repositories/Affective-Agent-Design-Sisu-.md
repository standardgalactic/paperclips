# Affective-Agent-Design-Sisu-

Summary:

Sisu is a gamified educational application aimed at helping school-aged children with reading difficulties. It integrates three core components: (1) a spelling game, (2) an empathic agent utilizing the Facial Action Coding System (FACS) to recognize and respond to the child's emotional states, and (3) a mini-game designed to reinforce learning. The application leverages readily available technology to facilitate home-based learning experiences, combining educational content with affective support to enhance motivation and engagement in reading practice.
