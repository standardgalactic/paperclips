# counterfactuals_dev

Summary:

The counterfactuals_dev repository contains anonymized datasets from multiple experiments focused on studying counterfactual reasoning in both adults and children. Each experiment (1, 2, and 3) provides separate CSV files for adult and child participants, including trial data (`*.csv`) and demographic information (`*_demographics.csv`). Experiment 3 additionally offers individual participant files for adults.
