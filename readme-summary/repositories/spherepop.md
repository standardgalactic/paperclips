# spherepop

**Summary**

`spherepop` is a research repository that investigates the conceptual foundations of “thought ecology” – treating digital workspaces as living cognitive habitats rather than static archives. It draws on several interrelated themes:

* **Algebra of Binding**, *Remainders and Residuals*, *Beyond Parentheses*, *Dependent Type Theory*, *Refusal Structures* – these texts explore algebraic, logical, and type‑theoretic frameworks that underpin how information is bound, retained, and differentiated.
* **Persistence Before Truth**, *The Fate of Distinguishability*, *The Ecology of Distinctions*, *Repairing Futures*, *Rotation Before Number*, *Memory Before Representation*, *Negation Before Logic*, *Economy of Forgotten Things* – these essays examine the primacy of historical persistence over logical truth, emphasizing that context and memory shape cognition.
* **Manuscript** (and related blog posts) articulate a manifesto: “The environment is not merely where thinking happens—it is part of the computational substrate from which thinking emerges.” The repository advocates for knowledge systems that preserve temporal stratification, maintain unfinished work, and support navigation alongside retrieval.

Key deliverables include:

- A set of linked PDF textbooks (e.g., *Algebra of Binding*, *Remainders and Residuals*) providing formal foundations.
- Blog posts such as **Stop Cleaning Your Desk**, **The Ecology of Thought: A Guide to Temporal Stratification in Memory Registers**, and **From Archive to Habitat** that operationalize these ideas.
- Technical proposals like **Architecting the Cognitive Habitat** and **Strategic Design Assessment** for building persistent, context‑preserving environments.

The repository also hosts visual assets (e.g., `spherepop-infographic.png`, `beyond-parentheses.png`) illustrating concepts visually. It is part of a broader research program called *Flyxion Research Program* (`research.md`).
