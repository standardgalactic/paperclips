# geometry-hysteresis

The repository geometry-hysteresis implements algorithms and models related to the phenomenon of geometry‑hysteresis specifically for Refreshable Raster Scanning (RSV) or Retinal Synchro Scan (RSS) display connectors. It addresses how mechanical geometry variations affect performance metrics in these high‑speed display interfaces, providing computational tools to simulate and analyze hysteresis effects under different operational conditions.
