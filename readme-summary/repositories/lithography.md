# lithography

SUMMARY:

The lithography repository focuses on research related to the lithography process critical for manufacturing PCBs (Printed Circuit Boards) and semiconductors. It covers various techniques including photolithography using UV light (wavelengths 193 nm, deep UV at 248 nm), electron beam lithography employing electron beams with sub-nanometer wavelengths, and extreme ultraviolet (EUV) lithography utilizing 13.5 nm wavelength light. Each method has distinct materials—photoresists for traditional and EUV processes, and electron-sensitive resists for E-beam—and offers specific benefits like resolution versus cost trade-offs.
