# corridor-routing

The corridor-routing repository implements a task-aware, negentropic (energy-efficient) routing algorithm designed for integrated circuit design. It focuses on minimizing the total wirelength and congestion while considering task dependencies to optimize performance in VLSI chip layouts. The project utilizes advanced graph theory concepts and integer linear programming to achieve its goals. Current implementation is considered experimental with ongoing development; some features may be incomplete or subject to change.

KEYWORDS:
corridor routing, integrated circuits, wirelength optimization, congestion reduction, task-aware routing, negentropic algorithms, VLSI design, graph theory, ILP, experimental software
