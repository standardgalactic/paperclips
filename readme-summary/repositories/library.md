# library

Summary:

The "library" repository is a collection of research papers and related artifacts centered on the philosophical and practical implications of verification, commitment, observability, and erasure within formal systems. It explores concepts such as the transition from verification to commitment (from-verification-to-commitment.pdf), the economic cost associated with knowing information (the Cost of Knowing), and how admissibility precedes truth in certain contexts (Admissibility Before Truth). Key theoretical frameworks include Observability is Restorability, Erasure is Deformation, and Geometry of Witnesses. Conservation of Ambiguity is also discussed but remains incomplete. The repository includes visual aids like verification-infographic.png and links to additional PDFs detailing each concept's application and implications.

KEYWORDS: library, verification, commitment, observability, erasure, witnesses, ambiguity, formal systems, research papers, theoretical frameworks.
