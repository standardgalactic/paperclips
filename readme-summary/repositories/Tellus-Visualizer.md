# Tellus-Visualizer

The Tellus-Visualizer repository provides an interactive visualization tool for exploring geospatial data sets generated by the Tellus simulation framework. It enables users to render three-dimensional representations of planetary surface features, atmospheric conditions, and subsurface structures in real-time, facilitating scientific analysis and educational outreach.

Key components include:
- Integration with Tellus output files (e.g., .tellusdata) using proprietary binary formats.
- Support for multi-resolution rendering via LOD (Level of Detail) algorithms to manage performance on varying hardware.
- Interactive controls such as zooming, panning, and toggling between different data layers (e.g., topography, temperature gradients).
- Export capabilities for generating high-resolution images or animations suitable for publication.

The project is currently in beta status, with ongoing development focusing on expanding supported file formats and improving rendering speed. Compatibility issues may arise with non-standard Tellus output versions.
