# mu-PINNs

Summary:

The mu-PINNs repository implements Multi-Viscosity Physics-Informed Neural Networks (μ-PINNs) as described in the paper "Multi-Viscosity Physics-Informed Neural Networks for Generating Ultra High Resolution Flow Field Data". It provides code and datasets to generate ultra-high resolution flow field data, allowing users to train models and make predictions. The repository includes directories for training points (`data/`), generating these points (`get_point_train/`), the trained model (`model/`), and examples using OpenFOAM simulations (`openfoam/`). Usage instructions detail how to run prediction scripts and utilize OpenFOAM for modifying viscosity values, running simulations, and visualizing results with Paraview. Proper citation is required for academic use.

KEYWORDS:
mu-PINNs, physics-informed neural networks, ultra-high resolution flow fields, OpenFOAM, fluid dynamics simulation, citation required
