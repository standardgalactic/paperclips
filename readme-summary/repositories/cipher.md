# cipher

Summary:
The Cipher repository contains a simple implementation of the Caesar cipher, a type of substitution cipher where each letter in the plaintext is shifted by a fixed number of positions defined by a key. The software takes two arguments: the filename containing the strings to be encrypted and the strings themselves. It can be compiled using GCC with the command `gcc -x c -o filename.exe filename.c`, or compatible C compilers may be used.
