# project

Summary:

Parsing Expression Grammar Notation (PEGN) is a formal notation designed for specifying parsing expressions, particularly useful in compiler construction and text processing applications. The repository serves as a redirect to related projects including:

- **pegn.dev**: Official website providing documentation and resources.
- **pegn-spec**: Repository containing the specification document for PEGN grammar rules and syntax.
- **pegn-go**: Reference parser implementation written in Go, demonstrating how to apply PEGN specifications.

The project is currently transitioning to a modular structure where individual projects (e.g., EMACs, Vim plugins) will be managed separately by their respective contributors. This change aims for better maintainability and scalability but requires patience as the linking infrastructure is being established.

KEYWORDS: PEGN, parsing expressions, grammar notation, compiler construction, text processing, specification document, reference parser, Go implementation, modular architecture, project transition.
