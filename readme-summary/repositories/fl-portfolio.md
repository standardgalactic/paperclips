# fl-portfolio

SUMMARY:

The fl-portfolio repository is a personal portfolio project by Facundo Ledesma, integrating art, music, and computer science. It serves as an artistic expression of his passions, inspired by websites like Bruno Simon's, Jesse Zhou's, and Jacek Jeznach's. The project is built using React, JavaScript, SCSS, Webpack, Babel for web development, and Procreate for animations and illustrations. Users can run the application locally by cloning the repository, installing NPM packages with `npm install`, and starting it in development mode via `npm start`. The software is licensed under the ISC License and is currently in its first version, with future updates planned.
