# catalogue-open-data-sante

SUMMARY:

The Catalogue Open Data Santé repository aims to centralize all publicly available health-related open data in France into a unified, common format with an interactive interface. This addresses the fragmentation issue caused by multiple data providers (e.g., INSEE, Santé Publique France) and sources offering various presentations of health datasets, ranging from epidemiological (flu, COVID-19) to hospitalization and pharmaceutical data.

The project's purpose is to enable citizens, stakeholders, and policymakers to easily access and verify health-related information. For instance, during flu epidemics or sudden increases in hospitalizations for specific conditions, the catalog will help authorities understand the actual situation to implement appropriate measures.

Developed by a data scientist working in healthcare, the repository faces challenges related to the overwhelming volume of available datasets and their lack of discoverability. The creator invites support through Tipeee for further development and improvement of the site.
