# linguistics

Summary:

The repository "linguistics" contains scholarly essays and related resources exploring how linguistic distinctions are preserved in language use through cognitive and reasoning frameworks. Key works include:

- **Why Distinctions Survive**: Explores the rationale behind preserving certain linguistic distinctions.
- **The Geometry of Reasoning**: Discusses geometric models for understanding reasoning processes.
- **The Persistence Hierarchy**: Outlines a hierarchy explaining why some distinctions persist over others.
- **The Hidden Architecture of Adjectives**: Analyzes structural aspects of adjectives that contribute to meaning preservation.
- **Substance and Accident**: Distinguishes between essential (substance) and non-essential (accident) properties in linguistic terms.
- **Geometric Admissibility** and **Reachability Theory**: Provide mathematical frameworks for determining which distinctions are admissible and how they affect navigational structure.

The central thesis is that language, cognition, and reasoning involve preserving navigational structures to support future actions, inference, repair, or decision-making. The repository includes visual aids (e.g., "distinctions-overview.png") and audio overviews of the main concepts via the Distinction Engine.
