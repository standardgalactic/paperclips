# GuitarMathematicalModel

Summary:

The GuitarMathematicalModel repository aims to develop a mathematical model for simulating the behavior of a guitar string and its associated head (eadrum) using numerical techniques implemented in Scilab. The project focuses on applying differential equations and wave propagation theories to accurately represent acoustic properties and vibrations of musical instruments.

KEYWORDS:
guitar modeling
numerical methods
scilab
wave equation
acoustic simulation
