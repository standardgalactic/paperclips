# neoteny-essay

**Summary**

The *neoteny‑essay* repository presents a theoretical framework for “steady‑state civilization” that argues civilisation’s long‑term vitality hinges on preserving neotenous cognition—curiosity, play, and exploration—within institutional niches. Using Alison Gopnik’s tripartite model of human intelligences (Exploit, Explore, Empower) it extends these ideas into an entropic framework where curiosity is treated as a thermodynamic variable that must be subsidized and regulated.

Key components include:

- **Neoteny** – retention of juvenile cognitive traits.
- **Cognitive Sanctuaries** – universities, research labs, etc., that subsidise exploration.
- **Entropy Converters** (Georgescu‑Roegen) – systems absorbing local disorder to preserve global order.
- **Steady‑State Equilibrium**: $$\frac{dS_{\text{usable}}}{dt}=0$$—maintaining usable entropy without perpetual material growth.
- **Thermodynamic Ethics**: morality as entropy management, balancing curiosity with care.

Core proposals:

1. **Universal Basic Income (UBI)** combined with incentive mechanisms to buffer and sustain curiosity.
2. **Geozotic Lottery** – spatially decaying innovation rewards:  
   $$R(x)=R_0 e^{-\lambda d(x,x_0)}$$
3. **Entropy Efficiency Index**:  
   $$\eta_S=\frac{\Delta I}{\Delta E}$$

The repository is organized into five parts covering neoteny and institutional scaffolding, entropic ethics of curiosity, collective autocatalysis & cooperative minima, aging as simulated annealing, and the steady‑state civilization model. An appendix provides ready‑to‑run agent‑based simulation code for modeling entropy subsidies.

**KEYWORDS:** neoteny, cognitive sanctuaries, entropy converters, steady‑state equilibrium, thermodynamic ethics, universal basic income, geozotic lottery, entropy efficiency index, curiosity preservation, institutional innovation, aging as simulated annealing.
