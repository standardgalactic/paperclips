# racer

Summary:

The "racer" repository is a class project for Evolutionary Robotics (2024) at the University of Vermont, developed by Josh Bongard. Its primary purpose is to serve as a prototype for future research and demonstrate an implementation of the NEAT (NeuroEvolution of Augmenting Topologies) algorithm. The project simulates co-evolutionary experiments where both the environment (a topographic map) and controllers for agents (rolling balls) are evolved using NEAT. Various coevolutionary dynamics are tested, generating log files, sample videos, and charts depicting fitness growth across different experiments.
