# carbon-lang-vscode

Summary:

The carbon-lang-vscode repository hosts an Visual Studio Code (VSCode) extension designed to provide enhanced support and development experience for the Carbon programming language. It integrates syntax highlighting, code completion, debugging capabilities, and other productivity features tailored specifically for Carbon projects within the VSCode environment.

Key aspects include:
- Purpose: To facilitate coding, testing, and debugging of applications written in Carbon by leveraging VSCode's extensibility.
- Core Features: Syntax highlighting, IntelliSense (code completion), integrated debugger support, and project-specific configuration options.
- Compatibility: Explicitly targets the Carbon language ecosystem, indicating dependencies on Carbon compiler and runtime environments.
- Status: Currently under active development; version numbers suggest an evolving feature set with ongoing bug fixes and performance improvements.
- Relationship: Directly complementary to other Carbon-related projects such as carbon-lang-runtime and carbon-docs, forming part of a cohesive toolchain for Carbon development.
