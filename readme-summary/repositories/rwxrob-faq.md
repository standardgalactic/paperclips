# rwxrob-faq

Summary:

The repository rwxrob-faq contains scripts and utilities for creating large color font titles in the terminal. It achieves this by combining the `figlet` command, which generates text art from fonts, with `lolcat`, a tool that adds rainbow colors to terminal output. The actual font collection is hosted separately at [repo].com/rwxrob/fonts), where various figlet fonts are organized under the `figlet` directory. A notable primary font used is `future`. Example scripts included are `figl` and `back`, both located in the dotfiles repository.

KEYWORDS: rwxrob-faq, terminal, figlet, lolcat, color font, text art, fonts repository, future font, scripts, back script.
