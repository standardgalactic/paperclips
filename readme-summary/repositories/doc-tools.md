# doc-tools

Summary:

The doc-tools repository contains a simple utility program designed to analyze text files. It calculates and returns three key metrics: the total number of lines, sentences, and words present in the input file. The project is straightforward, with no complex dependencies or integrations beyond basic C compilation tools (gcc, clang, tcc, or cc). Users can build the tool directly using the `make` command or manually via their preferred compiler. As stated in the README, the implementation appears to be a minimal, functional prototype rather than an advanced or feature-rich solution.
