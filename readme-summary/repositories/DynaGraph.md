# DynaGraph

Summary:

DynaGraph is an implementation of Dynamic Contrastive Graph (DCG) designed for interpretable multi-label prediction using time-series Electronic Health Record (EHR) data from datasets like eICU, MIMIC-III, HiRID ICU, and EHRSHOT. The repository provides installation instructions via pip, detailed notebooks for data extraction and preprocessing steps, and references external resources for accessing large dataset files due to size constraints. Training and evaluation scripts are included, allowing users to adjust model parameters and run evaluations using specific seeds. Interpretability features are demonstrated through visualization of weights on test sets, with saved weights available for eICU and MIMIC-III datasets.

KEYWORDS:
DynaGraph, Dynamic Contrastive Graph, EHR, Electronic Health Records, time-series data, multi-label prediction, eICU, MIMIC-III, HiRID ICU, interpretability, visualization, weights.
