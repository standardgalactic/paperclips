# abraxas

Summary:

The abraxas repository houses the Mem|8 rebuttal to Xylomorphic Computation and its extensions into economic theory and covenant design. Key components include:

- **Research Paper**: “MEM-8_and_Marine_Algorithm_Research” delves into algorithmic underpinnings and their implications for governance.
- **Full Covenant Document**: PDF version of the Petabyte Covenant with disclaimer.

The repository also contains an audio explainer (“Ayian Unpacked”) detailing work‑backed crypto, persona‑bound value, and hybrid governance models.
