# paperpal

Summary:

PaperPal is an MCP (Model Context Protocol) extension designed to enhance literature review workflows by integrating access to major academic repositories—arXiv, Hugging Face Papers, and Semantic Scholar—with large language models (LLMs) such as Claude. It enables users to engage in natural conversations about research papers, discover new relevant literature, and organize ideas for writing literature reviews directly within their preferred LLM interface.

Key features include:
- Seamless integration with arXiv, Hugging Face Papers, and Semantic Scholar.
- Interaction via existing LLM tools like Claude Desktop App or Cursor.
- Capabilities for discussing specific papers, searching for related research, and structuring review content.
- Acknowledges limitations such as potential hallucinations by LLMs and imperfect semantic search results.

Implementation status indicates that PaperPal relies on the quality of its underlying components; thus, it is considered a tool whose effectiveness depends on the strengths of those parts. The README provides detailed quickstart instructions for integrating PaperPal with Claude Desktop App or Cursor, including configuration file modifications and server command setups.
