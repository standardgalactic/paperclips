# drawing

Summary:

The repository "drawing" serves as an archive and research platform for exploring how drawings are ordered and their role in thinking processes. It includes essays and figures that examine the development of graphic representation, supported by references to external works such as *Making Thought Visible* (https://standardgalactic.github.io/drawing/making_thought_visible.pdf). The project features an interactive study called "Drawing order" (https://standardgalactic.github.io/drawing/) which allows users to reorder marks and share sequences via URLs. This tool is a conceptual demonstration rather than empirical data from developmental studies. Additionally, there are personal archives of childhood drawings and older artwork available at https://standardgalactic.github.io/archive, intended as records of one individual's drawing history.

KEYWORDS: drawing theory, graphic representation, thought visualization, interactive study, archival art
