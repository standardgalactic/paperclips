# rwxcv

Summary:

The repository "rwxcv" contains a resume formatted as an HTML document generated from YAML structured data and Go template syntax. The purpose is to showcase IT infrastructure engineering, operations, and systems software design and development skills. It includes instructions on how to regenerate the `index.html` file using the provided `gen.go` script. The implementation is currently functional for personal use but may require updates or adjustments for broader applicability.

KEYWORDS:
resume generation, YAML data, Go templates, IT infrastructure, software developer, template engine
