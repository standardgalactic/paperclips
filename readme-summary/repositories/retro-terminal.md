# retro-terminal

SUMMARY:
Retro Terminal is a software project that recreates historical terminal interfaces and command-line environments from early computing eras. It aims to serve as software archaeology by implementing features such as fixed-size screen buffers, printable text rendering with line wrapping and scrolling, control handling for various terminal commands (e.g., newline, carriage return), and ANSI CSI support for cursor movement and color styling. The current version is 0.1.0 and includes unit tests for core functionalities like wrapping, scrolling, and control behavior. Development is managed via a Makefile with tasks including linting, testing, benchmarking, documentation generation, formatting, and release handling through the `scripts/manage.sh` helper script.
