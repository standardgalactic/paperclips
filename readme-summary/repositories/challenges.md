# challenges

Summary:

The "challenges" repository contains a simple programming challenge titled "Hello World Challenge." Its purpose is to prompt participants to write a basic program that meets specific criteria. The required program, named `hello`, must be executable from the command line using only its name and should output exactly `Hello World!` on one line. This exercise serves as an introductory task for learning or demonstrating fundamental programming concepts in a minimalistic environment.
