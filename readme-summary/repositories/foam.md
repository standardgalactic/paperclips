# foam

SUMMARY:

Foam is a knowledge management system designed for personal note-taking and organization using Markdown (Bubbles) within a GitHub-hosted workspace. It provides structured templates via Visual Studio Code extensions to facilitate quick setup, categorization of notes, and tracking tasks. The repository includes essential documentation such as "inbox" for raw notes, "getting-started" guide, and "todo" list management. Users are encouraged to refer to the main Foam documentation site for broader usage instructions and community support via Discord.

KEYWORDS: Foam knowledge base, GitHub template, Visual Studio Code, Markdown Bubbles, personal note-taking, task tracking, community Discord, issue submission main repository.
