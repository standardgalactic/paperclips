# typing-tutor

Summary:

Retro Typing Tutor v5 is a single-window, green/amber CRT-style typing application designed for practicing both QWERTY and Dvorak keyboard layouts. It automatically alternates between the two layouts every 4–10 words using paired essays optimized for each layout. The simulation of Dvorak spans occurs via physical keycode mapping without requiring any operating system changes to the keyboard layout. Additional features include a boot animation with subtle scanlines, periodic refresh surges, and the use of VT323 font. Users can run the application by opening `index.html` in a modern browser, with functionality for backspacing, ignoring Enter keys, regenerating mixed lines, and toggling sound effects for key clicks or errors.

KEYWORDS:
typing tutor, QWERTY, Dvorak, alternating layout, CRT emulator, paired essays, keycode mapping, boot animation, scanlines, VT323 font, modern browser, auto-switching.
