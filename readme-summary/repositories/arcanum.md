# arcanum

Summary:

Arcanum is a Rust laboratory repository containing self-contained programs that demonstrate core features of the Rust programming language. Each lesson resides in its own directory with a single `main.rs` file, compilable and runnable independently using the Rust compiler (`rustc`). Compilation instructions are provided for individual lessons and all lessons collectively. A compile check script verifies successful compilation without executing the binaries. Cleanup scripts remove generated executables. The repository is structured sequentially but allows independent study of each lesson, focusing on single topics and relying solely on the Rust standard library.

KEYWORDS: Rust programming language, self-contained programs, tutorial, compiler (rustc), lessons, sequential learning, standard library, cleanup scripts, compile check.
