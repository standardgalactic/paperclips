# REPeatedOPtogeneticStimulation

Summary:

The REPeatedOPtogeneticStimulation repository provides analysis code and processed datasets for the study "Repetitive Neuronal Activation Regulates Cellular Maturation State via Nuclear Reprogramming" by Murano et al., published on bioRxiv in 2015. It contains scripts (in R and Python), processed data, and generated figures/summary tables necessary to reproduce the main analyses described in the paper. Raw datasets are omitted due to size constraints, but the repository is designed for reproducibility using standard software environments with specified package versions that may be updated later. The code is licensed under the MIT License.

KEYWORDS:
Repetitive neuronal activation, cellular maturation, nuclear reprogramming, Murano 2015, bioRxiv, MIT license, R Python analysis, processed datasets
