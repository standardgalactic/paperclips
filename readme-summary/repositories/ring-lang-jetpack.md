# ring-lang-jetpack

Summary:

The ring-lang-jetpack repository provides Japanese localization packages for the Ring programming language, known as RingPM (Ring Package Manager). It is currently under construction and not yet fully mature. Installation can be performed either online via "ringpm install ring-lang-jetpack from pancakevirus" or offline following instructions on https://osdn.net/projects/ring-lang-081/. The repository includes documentation in Japanese, located at documents/build/html_ja-jp/_sources/*.txt, and welcomes corrections for translation errors through pull requests.
