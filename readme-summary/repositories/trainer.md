# trainer

Summary:

SGA Trainer is a web-based tool designed to assist users in mastering the Standard Galactic Alphabet, often associated with Minecraft Enchantment Table language. Key features include a simple and visually appealing user interface, an elegant font for easy memorization, and offline access capability by saving the webpage as HTML and using Local Mode when internet connectivity is unavailable. The tool currently integrates with the Random Word API to provide access to over 170,000 words. Notable limitations are indicated by displaying "error" messages if the Random Word API encounters issues, prompting users to switch to Local Mode for continued functionality.

Upcoming enhancements under consideration are a notification system, settings page for customizing APIs and fonts, and an XP (experience) tracking feature.

The project is open for contributions; interested parties can report issues or submit pull requests. The repository acknowledges inspiration from DioriteTM's Standard Galactic Trainer at https://www.dioritetm.xyz/sga.
