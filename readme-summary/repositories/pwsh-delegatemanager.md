# pwsh-delegatemanager

Summary:

The DelegateManager repository provides a PowerShell tool designed to manage delegate permissions for mailboxes within Exchange Online. As of version 0.0.1, the project is still in early development (WIP) and only includes two functional features out of its planned set: adding new delegate permissions and generating a list of existing delegate permissions. Future enhancements such as removing delegate permissions, modifying existing ones, and implementing logging are pending.

Requirements include PowerShell version 7.x with the ExchangeManagementOnline module installed, and access to an account with appropriate Exchange Online permissions.

Usage involves importing the module from the repository's directory and executing the Manage-Delegates command within that context.
