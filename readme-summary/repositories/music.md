# music

Summary:

The "music" repository is a command-line tool designed to track and notify users about new music releases from their favorite playlists on various music streaming services, currently supporting Spotify and Yandex. Users can add playlists using specific service identifiers, synchronize the data to detect new releases, and view the resulting list of upcoming tracks with details such as release dates, artists, genres, and album information. The tool supports exporting and importing playlist lists via JSON files.

Key concepts include:
- Playlist management across supported music services.
- Notification system for new releases based on synced playlists.
- Genre and type filtering for released tracks (e.g., album-specific outputs).
- CLI-driven operations with commands like `playlist add`, `release list`, and file export/import functionalities.

The project is not yet complete, as indicated by the roadmap mentioning upcoming Deezer integration and email notifications for new releases.
