# LangSLT

SUMMARY:

The LangSLT repository provides a dataset and associated software for describing American Sign Language (ASL) actions using a structured format: <Gestures: [Description]; ...>, along with metadata such as Nation, Language, and context. The DailyMoth-70h dataset, sourced from publicly available videos of ASL interpreters covering news content, is licensed under Creative Commons Attribution-NonCommercial 4.0 International, allowing only non-commercial academic use with proper attribution. Installation requires a conda environment with Python 3.10, followed by cloning the repository and installing dependencies via pip. Prompt templates guide model training to output sign language action descriptions in specified formats and languages.

KEYWORDS:
LangSLT dataset, American Sign Language, ASL actions description, Creative Commons license, DailyMoth project, sign language expert prompts, conda environment setup, Python 3.10 installation, prompt templates for translation.
