# Applied-Deep-Learning

Summary:

The Applied-Deep-Learning repository is an educational project associated with COMS 4995 at Columbia University, developed by Zhenhao Li. It serves as a practical application of deep learning techniques through various experiments and implementations. The repository includes code for training and deploying neural networks on image classification tasks using TensorFlow and Keras frameworks. Key concepts covered are convolutional neural networks (CNNs), data augmentation, transfer learning, and hyperparameter tuning. Notable artifacts include pre-trained models on the CIFAR-10 dataset and notebooks demonstrating end-to-end pipeline setups from data preprocessing to model evaluation. The implementation status is considered intermediate, with some components still under active development and lacking comprehensive documentation or optimization for production environments. Relationships are explicitly stated with other projects like "Deep-Learning-Basics" for foundational concepts and "Vision-Projects" for related image processing tasks.

KEYWORDS:
deep learning, TensorFlow, Keras, CNNs, CIFAR-10, data augmentation, transfer learning, COMS 4995, Columbia University, Zhenhao Li
