# keg-spec

Summary:

The keg-spec repository defines a structured system for organizing knowledge content using specific terminology such as node, dynamic node, included node, secondary node, orphan node, and broken link. It distinguishes between static (non-generator) and dynamic nodes that require generation processes. Key file types include README.md, DATA.* files, text nodes containing KEGMark text, collection nodes with bulleted import lists, and composite nodes generated from other nodes (e.g., books). The repository also introduces the concept of an isosec—a timestamp in a specific ISO8601 format without punctuation or 'T'—for uniquely identifying content based on GMT time. Relationships among these elements are explicitly stated to facilitate navigation and integration within larger knowledge ecosystems.
