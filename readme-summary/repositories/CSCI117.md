# CSCI117

Summary:

CSCI117 is a repository focused on exploring the fundamental structures and paradigms inherent in programming languages. It utilizes Mozart/Oz files to demonstrate various concepts such as scope and binding rules. The project aims to provide practical applications and implementations of these language constructs, serving as an educational resource for understanding how programming languages are structured and function.
